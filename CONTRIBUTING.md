# Contribuir a Net-Map

¡Gracias por tu interés! Net-Map es código abierto y recibe contribuciones.

## Cómo contribuir

1. Haz fork del repositorio.
2. Crea una rama: `git checkout -b feature/mi-aporte`.
3. Haz tus cambios con pruebas cuando aplique.
4. Abre un Pull Request describiendo qué cambiaste y por qué.

## Reglas

- Código claro, comentado y sin dependencias innecesarias.
- Respeta la estructura de `src/` y `docs/`.
- No incluyas modo monitor ni funciones fuera del alcance del proyecto.
- Sé respetuoso: aplica el `CODE_OF_CONDUCT.md`.

## Reportes

- Bugs y mejoras: abre un Issue con pasos para reproducir.
- Vulnerabilidades de seguridad: **no** abras Issue público; usa `SECURITY.md`.
